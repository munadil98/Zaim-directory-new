# যয়ীম ডিরেক্টরি - মজলিস আনসারুল্লাহ্, বাংলাদেশ

এটি একটি রিয়েক্ট (React) ভিত্তিক ওয়েব অ্যাপ্লিকেশন যা গুগল শিট (Google Sheets) থেকে স্বয়ংক্রিয়ভাবে তথ্য সংগ্রহ করে মজলিস আনসারুল্লাহ্, বাংলাদেশ-এর যয়ীমদের ডিরেক্টরি প্রদর্শন করে।

## বৈশিষ্ট্যসমূহ
- **রিয়েল-টাইম ডাটা:** গুগল শিটে তথ্য পরিবর্তন করলে অ্যাপে তা অটোমেটিক আপডেট হয়।
- **সার্চ সুবিধা:** নাম, মজলিস বা জেলা দিয়ে দ্রুত তথ্য খোঁজা যায়।
- **সরাসরি যোগাযোগ:** এক ক্লিকেই কল বা হোয়াটসঅ্যাপ মেসেজ পাঠানোর সুবিধা।
- **রেসপনসিভ ডিজাইন:** মোবাইল এবং ডেস্কটপ—উভয় ডিভাইসেই সুন্দরভাবে কাজ করে।

## গিটহাবে আপলোড করার নিয়ম (GitHub Upload Instructions)

আপনি যদি এই কোডটি গিটহাবে আপলোড করতে চান, তবে নিচের ধাপগুলো অনুসরণ করুন:

### ১. গিটহাব রিপোজিটরি তৈরি করুন
- আপনার গিটহাব অ্যাকাউন্টে লগইন করুন।
- **New Repository** বাটনে ক্লিক করুন।
- রিপোজিটরির একটি নাম দিন (যেমন: `zaeem-directory`) এবং **Create repository**-তে ক্লিক করুন।

### ২. কোড আপলোড করুন (সহজ পদ্ধতি)
- আপনার রিপোজিটরিতে গিয়ে **uploading an existing file** লিঙ্কে ক্লিক করুন।
- আপনার কম্পিউটার থেকে `index.html` ফাইলটি ড্র্যাগ করে সেখানে ছেড়ে দিন।
- **Commit changes** বাটনে ক্লিক করুন।

### ৩. গিটহাব পেজেস (GitHub Pages) চালু করুন
- রিপোজিটরির **Settings** ট্যাবে যান।
- বাম পাশের মেনু থেকে **Pages**-এ ক্লিক করুন।
- **Branch** সেকশনে `main` সিলেক্ট করুন এবং ফোল্ডার হিসেবে `/(root)` রেখে **Save** করুন।
- কিছুক্ষণ পর আপনাকে একটি লিঙ্ক দেওয়া হবে (যেমন: `https://yourusername.github.io/zaeem-directory/`), যেখান থেকে সবাই অ্যাপটি ব্যবহার করতে পারবে।
